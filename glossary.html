車用微控制器與高精度類比 PMIC 專業術語辭典

彙整車用 MCU、雙通道 ΔΣ AFE、電源管理 PMIC、BMS 電池演算法、BCD 智慧功率半導體製程與 ISO 26262 功能安全核心縮寫、定義、數值指標與對應章節。

Arm® Cortex®-M0+ 32 位元低功耗處理器核心

核心微架構

2 級管線（Fetch、Execute）的 ARMv6-M 核心，NVIC 最多 32 個中斷、4 級優先，中斷延遲 15 週期（零等待狀態）。HVPA 依料號運作於 24 或 48 MHz。

Arm 公布約 2.46 CoreMark/MHz、0.93 DMIPS/MHz。 前往相關章節 →

Single-cycle I/O port 單週期 I/O 埠（IOPORT）

核心微架構

Cortex-M0+ 的架構選配：核心不經 AHB 仲裁直接存取 GPIO 暫存器。是否實作與位址由晶片廠決定。

只省下數十 ns；外部驅動器與致動器時間通常大得多。 前往相關章節 →

SECDED ECC 單錯修正、雙錯偵測

核心微架構

32 位元資料加 6 個 Hamming 檢查位元與 1 個整體同位位元，組成 39 位元碼字。症狀碼指出單錯位置以修正；雙錯只能偵測。

DS：SRAM、Code Flash、Data Flash 都有 ECC；單錯在線修正並記錄位址與資料。 前往相關章節 →

DMA 直接記憶體存取

核心微架構

不經 CPU 搬移資料的引擎，常用於把 ADC 結果送進 SRAM 的 ping-pong 緩衝，讓 CPU 保持睡眠。

DS：8 通道、32 位元傳輸、可串接 ping-pong 描述符。 前往相關章節 →

Deep Sleep 深度睡眠模式

核心微架構

CPU 與高速時脈關閉，低功耗振盪器、計時器、LIN 與看門狗保持運作；所有 RAM 內容保持。

DS：35 µA typ（無週期喚醒）；每秒喚醒量測 85 µA typ；喚醒 ≤ 35 µs。 前往相關章節 →

IMO / HPOSC / PILO / ILO 晶片內振盪器

核心微架構

IMO 為主時脈（最高 49.152 MHz）；HPOSC 是 2 MHz ±1% 的校準參考；PILO 32 kHz 驅動看門狗與喚醒計時；ILO 40 kHz。

DS：IMO ±2%，以 HPOSC 軟體校準後 ±1% 或 ±1.5%。 前往相關章節 →

PACSS 精密類比通道子系統

類比與感測

HVPA 的類比前端：兩顆 ΔΣ ADC、電流／電壓／溫度／診斷通道、序列器、數位濾波與窗口比較。任一 ADC 都能連到任一類比訊號，方便交叉檢查。

DS：ADC 16–20+ 位元；ADC 滿量程輸入 1.2 V。 前往相關章節 →

Kelvin 4-wire 四端子凱爾文接線

類比與感測

大電流走外側端子，量測線直接取自電阻本體，排除焊點與走線電阻。對 100 µΩ 分流器是必要條件。

搭配對稱 RC 濾波，例：100 Ω + 100 nF → 約 7.6 kHz。 前往相關章節 →

Chopper stabilisation 斬波穩零

類比與感測

放大前把輸入極性週期性反轉，放大後再反轉回來，使放大器自身的偏移與 1/f 雜訊被搬到高頻，再由數位濾波器濾除。

無法消除分流器上的熱電勢等真實輸入誤差。 前往相關章節 →

ΔΣ ADC Delta-Sigma 類比數位轉換器

類比與感測

以超取樣與雜訊整形把量化雜訊推到高頻，再由抽取濾波器濾除。二階調變器的 NTF = (1 − z⁻¹)²。

DS：HVPA 使用多位準（multi-level）調變器。 前往相關章節 →

AGC & scaler 自動增益控制與正規化

類比與感測

比較器監看輸入，超過門檻時查找表同時調整 PGA、調變器增益與 scaler（×512/G），使 LSB 權重不隨增益改變。

DS：電流通道增益 1–512；100 µΩ 時 1 LSB = 0.715 mA。 前往相關章節 →

Sinc³ / Sinc² decimation 抽取濾波器

類比與感測

Sinc 濾波器（CIC）以累加與差分實現，零點在輸出資料率的整數倍。HVPA 依序為 Sinc³、Sinc² 與 16 tap 可程式 FIR。

DS 範例：3.072 MHz、OSR 64 → 48 kHz；DR2 48 → 1 kHz 零點。 前往相關章節 →

Bandgap reference 能隙基準

類比與感測

把正溫度係數的 kT/q 與負溫度係數的 VBE 加權相加，得到約 1.2 V、溫漂很低的參考電壓。

通常在晶圓測試時修調。 前往相關章節 →

HV regulator 高壓穩壓器

類比與感測

由電瓶 VBAT 直接產生 3.3 V 的 VDDD 與 VDDA；核心穩壓器再產生 1.8 V VCCD。

DS：VBAT 3.6–28 V 工作，可運作至 42 V（絕對最大 42 V）。 前往相關章節 →

IBS 智慧電池感測器

車用與電池

裝在 12 V/24 V 電瓶負極端子上的模組，量測電流、電壓與溫度，計算 SoC/SoH，經 LIN 回報車身控制器。

HVPA 的主要目標應用（鉛酸電池監測）。 前往相關章節 →

Coulomb counting 安時積分

車用與電池

以電流積分追蹤 SoC：SoC(t) = SoC(t₀) − (1/Qn)∫I dt。偏移會被線性累積。

1 µV 偏移在 100 µΩ 上 = 10 mA，30 天累積 7.2 Ah。 前往相關章節 →

OCV 開路電壓

車用與電池

電池充分靜置、電流接近零時的端電壓，可查表得到 SoC，用來重新定錨庫倫積分。

鉛酸電池通常需靜置數小時；結果受溫度影響。 前往相關章節 →

SoH / internal resistance 健康狀態與內阻

車用與電池

啟動時同步量測電壓下陷與電流步階，R = ΔV/ΔI；內阻長期上升代表老化。

比較前需做溫度補償。 前往相關章節 →

LIN 區域互連網路

車用與電池

單線、主從式車載匯流排，通常 19.2 kbit/s。訊框為主節點 header（Break、Sync 0x55、PID）加從節點 response（資料、checksum）。

DS：相容 LIN 2.2A / ISO 17987 / SAE J2602；LIN 腳 −27 V 至 +42 V。 前往相關章節 →

BDU 電池斷路單元

車用與電池

高壓電池包內的主接觸器、預充電路、電流感測與火工切斷器。接觸器以 PWM 節能保持、以齊納箝位加速斷開。

不是 HVPA 的目標應用（HVPA 最高 42 V）。 前往相關章節 →

Seebeck thermo-EMF 熱電勢

車用與電池

異質金屬接面在溫差下產生電壓。分流器兩端溫差會產生真實的偏移電壓，被庫倫積分累積。

對策：熱對稱、低熱電勢合金、零電流校準。 前往相關章節 →

ISO 26262 / ASIL 道路車輛功能安全

功能安全

以 ASIL A–D 分級，對開發流程與硬體指標（SPFM、LFM、PMHF）提出要求。

DS：HVPA 符合 ASIL C 流程要求與 ASIL B 硬體架構指標。 前往相關章節 →

SPFM 單點故障指標

功能安全

SPFM = 1 − Σ(λSPF + λRF) / Σλ，衡量單點與殘餘故障被涵蓋的程度。

目標：ASIL B ≥ 90%、C ≥ 97%、D ≥ 99%。 前往相關章節 →

LFM 潛伏故障指標

功能安全

衡量潛伏的多點故障被偵測的比例。

目標：ASIL B ≥ 60%、C ≥ 80%、D ≥ 90%。 前往相關章節 →

FIT / PMHF 失效率與隨機硬體失效機率

功能安全

1 FIT = 每 10⁹ 元件小時 1 次失效。PMHF 是系統層的隨機硬體失效率。

PMHF 目標：ASIL B/C < 100 FIT、D < 10 FIT。 前往相關章節 →

FMEDA 失效模式、影響與診斷分析

功能安全

把每個電路區塊拆成失效模式、分配失效率與診斷涵蓋率，計算 SPFM、LFM 與 PMHF。

ISO 26262-5 的核心量化方法。 前往相關章節 →

Challenge-response WDT 問答式窗口看門狗

功能安全

除了限制餵狗時間窗口，還要求送出正確的金鑰序列，證明安全任務確實執行。

DS：太早、太晚或金鑰錯誤 → 重置或中斷，原因記錄於 Reset Cause。 前往相關章節 →

Open-wire diagnosis 斷線診斷

功能安全

注入微小診斷電流或交叉量測，偵測分流器焊點或量測線開路，避免浮接輸入看起來像正常讀值。

HVPA 提供備援參考與量測路徑冗餘（DS）。 前往相關章節 →

BCD process Bipolar-CMOS-DMOS 製程

製程與車規

在同一晶圓整合精密雙極元件、高密度 CMOS 與高壓 DMOS 的混合訊號製程。

Infineon 未公開 HVPA 的確切製程。 前往相關章節 →

LDMOS 橫向雙擴散 MOS

製程與車規

以長且輕摻雜的漂移區承受高汲極電壓的功率電晶體，用於高壓穩壓器與 LIN 驅動等。

崩潰電壓提高的代價是導通電阻與面積。 前往相關章節 →

DTI 深溝槽隔離

製程與車規

以介電質溝槽隔開元件，阻擋高壓區注入基板的載子與雜訊，降低閂鎖風險。

常與保護環、分區佈局一起使用。 前往相關章節 →

Load dump 拋負載

製程與車規

發電機充電中電瓶斷開造成的長時間過壓。ISO 16750-2 Test A 未抑制（12 V：79–101 V），Test B 由發電機內抑制（常見 35 V）。

DS：VBAT 絕對最大 42 V，可能需要外部保護。 前往相關章節 →

AEC-Q100 車用 IC 應力驗證

製程與車規

汽車電子協會的 IC 驗證規範。Grade 1 為 −40 至 +125 °C；HTOL 1000 小時、3 批 × 77 顆零失效。

DS：HVPA 為 AEC-Q100 qualified，TA −40 至 125 °C。 前往相關章節 →

Trimming 修調

製程與車規

晶圓測試時量測每顆晶粒並寫入校正碼，補償偏移、增益與溫漂。殘餘誤差約為步階/√12 加上量測雜訊。

可在互動實驗室用 Monte Carlo 試算。 前往相關章節 →

Wettable-flank QFN 側面可潤濕 QFN

製程與車規

引腳側面有電鍍凹階的 QFN，焊錫會形成可見側面焊角，AOI 可直接檢查焊點。

DS：HVPA 為 32-QFN 6 × 6 mm wettable flank。 前往相關章節 →
