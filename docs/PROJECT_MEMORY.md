## Verified device facts — PSoC™ 4 HVPA-144K
Source: Infineon datasheet 002-28660 Rev. *K (2024-03-19). Rev. *L (2026-05) exists; re-check if updating.

| Topic | Value | Where |
|---|---|---|
| CPU | Cortex-M0+, 24 or 48 MHz (part-dependent); MPU present | Features |
| Memory | ≤128 KB code flash, ≤8 KB data flash, ≤8 KB SRAM, all ECC (SECDED); 1 KB SFlash | Features |
| DMA | 8 channels, 32-bit, chainable ping-pong descriptors | §1.1.6 |
| Power modes | Active, Sleep, Deep Sleep only (no Hibernate) | §1.2.1 |
| VBAT | 3.6–28 V operating, functional to 42 V; abs max 42 V | §1.2.1, SIDA5 |
| HV protection | “external protection (series R, diode, TVS) may be required” | Abs-max note 2 |
| VBAT filter | R1 10–15 Ω + C1 2.2 µF (20 mA) or 6.6–10 Ω + 2×2.2 µF (30 mA); external reverse diode | Fig. 1, Table 1 |
| Rails | VDDD/VDDA 3.3 V (may drop to 2.7 V when VBAT < 4 V); VCCD 1.8 V; VDDD ext. load ≤ 10 mA | §1.2, §1.6 |
| BOD | VCCD 1.48–1.62 V (Active/Sleep), 1.11–1.5 V (Deep Sleep) | §1.2.2 |

| Sleep | 3 mA typ | SID14 |

| ADC full scale | 1.2 V input | §1.9 |
| Current gain | 1–512; AGC example uses 4–512, 3000 A FS; scaler ×512/G; LSB 0.715 mA (100 µΩ) | §1.8.4–1.8.5 |
| Voltage divider | 24× (28.8 V FS) or 16× (19.2 V FS); ~2.4 MΩ; ext. 2.2 kΩ on VSENSE/VDIAG | §1.9 |

| LIN | Integrated PHY; LIN 2.2A/2.1/2.0/1.3, SAE J2602, ISO 17987; pin −27…+42 V; 10/20 kbit/s, 100 kbit/s fast mode | Features, §1.9 |

| Temperature | TA −40…125 °C; TJ −40…150 °C; storage −55…125 °C; AEC-Q100 | SIDA18–20 |
| Package | 32-QFN 6×6 mm, wettable flanks, ≤ 9 GPIOs | Features |
| Safety claim | ISO 26262: ASIL C **process**, ASIL B **hardware architectural metrics** | Features |

Standards used on the site: ISO 26262-5 targets (SPFM B/C/D ≥90/97/99 %, LFM ≥60/80/90 %,

- `favicon.ico` 404s appear on whichever page loads first; pages now use an inline SVG favicon. 2026-10-24 · Claude
