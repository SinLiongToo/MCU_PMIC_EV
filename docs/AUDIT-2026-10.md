### Factual errors (site claim → datasheet / standard)
| Site claimed | Correct |
|---|---|
| Chip has an on-chip 38.5 V LDMOS clamp that replaces an external TVS | Not in datasheet; DS says external protection (R, diode, TVS) may be required; VBAT abs max 42 V |
| Load dump = ISO 7637-2 Pulse 5b, 40–42 V | ISO 16750-2 Test A (12 V: 79–101 V) / Test B (suppressed, commonly 35 V) |
| "ISO 26262 ASIL-C ready/certified", SPFM 98.4 %, LFM 85.2 %, PMHF < 18 FIT | ASIL C process, ASIL B hardware metrics; no published HVPA SPFM/LFM/PMHF values |
| SPFM = Σcovered/Σλ (formula inverted) | SPFM = 1 − Σ(λSPF+λRF)/Σλ |
| Deep Sleep 12–15 µA; "Hibernate < 5 µA" | 35 µA typ (no wake-up), 85 µA with 1 Hz measurement; no Hibernate mode |
| PGA gain 1–64×, ±150 mV full scale | Gain 1–512; ADC FS 1.2 V → ±1.2 V/G; LSB 0.715 mA at 100 µΩ |
| 1-bit ΔΣ modulator / 1-bit DAC | Multi-level modulator |
| 1.536 MHz + OSR 1536 gives 50/60 Hz notches | That gives 1 kHz nulls; 50/60 Hz needs a 100 ms averaging window |
| Double-bit ECC → NMI | Reported to the fault system → interrupt or reset (as configured) |
| ILO 32 kHz drives WDT | PILO 32 kHz drives WDTs; ILO is 40 kHz |
| IMO ±0.5 % over temperature | ±2 %, ±1/±1.5 % after HPOSC calibration |
| Chopping removes Seebeck drift | Chopping removes amplifier offset only; thermo-EMF is a real input |
| Cortex-M0 had "fixed priority grouping"; 0.93 CoreMark/MHz | M0 and M0+ both 32 IRQs / 4 levels; ~2.46 CoreMark/MHz (0.93 DMIPS/MHz) |
| Fast I/O fires a 12 V pyro-fuse from the chip in < 20 ns | IOPORT is an architectural option; 12 V driver is external; end-to-end time is ms |
| "Real incidents" in Lessons | Relabelled as representative teaching scenarios |
