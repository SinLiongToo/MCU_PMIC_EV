Chapter 01 · Core & Microarchitecture Circuits

核心微架構：計算、匯流排與硬體安全電路原理

在車用微控制器（MCU）中，微架構必須保證中斷的微秒級確定性響應，並在硬體底層建立單粒子翻轉（SEU）的自動修復電路。以 Infineon PSoC™ 4 HVPA-144K 為基準，本章深度解析 Arm® Cortex®-M0+ 運算核心、單週期 Fast I/O 電平轉換驅動電路、單層 AHB-Lite 匯流排拓撲，以及全硬體 SECDED 漢明碼 XOR 糾錯電路架構。

1. 單週期 Fast I/O 匯流排與點火驅動電平轉換 (Level Shifter) 電路原理

傳統微控制器由 CPU 操作 GPIO 引腳時，指令必須經過標準系統匯流排（AHB/APB）與外設橋接仲裁器，引發 2 到 4 個時脈週期的延遲。在電池短路事故中，Pyro-fuse（火工熔斷器）的引爆必須在數十微秒內完成。Cortex-M0+ 建立了獨立的專屬單週期 I/O 匯流排（Single-Cycle Fast I/O Port），將核心暫存器直連至 I/O 輸出鎖存器，並配合 1.8V 至 12V 的高壓電平轉換前置驅動電路。

2. SRAM SECDED 漢明碼硬體 XOR 邏輯糾錯電路架構

車載環境中高能宇宙射線中子引發的單粒子翻轉（SEU）可能在任意時間將 SRAM 的位元從 0 變為 1。PSoC™ 4 HVPA 採用全硬體組合邏輯單錯修正、雙錯檢測（Single Error Correction, Double Error Detection, SECDED）電路，其解碼與校正完全在單個時脈週期內透明完成，不佔用任何 CPU 執行週期。
